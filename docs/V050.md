# Nass MCP v0.5.0 — Acquisition fallback

Optional operator-configured Invidious captions and optional yt-dlp `mweb` extraction attempt. Both are disabled by default and maintain fallback to original providers.

Configure `NASS_INVIDIOUS_URL=https://YOUR-TRUSTED-INSTANCE` (sends public video IDs to instance), or install/configure a compatible yt-dlp PO Token Provider then set `NASS_ENABLE_MWEB_POT=1`. The flag does **not** generate a token by itself. `nass_acquisition_report` shows nonsecret setup information and does not test live availability.

Test: `pip install -e '.[test]'`, `python -m compileall -q src`, `pytest -q`.

Sources: https://github.com/yt-dlp/yt-dlp/wiki/PO-Token-Guide ; https://docs.invidious.io/api/

No external credentials, proxy bypass, restricted-video access, or paid API are required. Neither optional provider guarantees access. Production requires real YouTube and ASR smoke tests on the target host; do not confuse install success with transcript success.
